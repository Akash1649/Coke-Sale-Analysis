# Coke Sales Analysis Project

## Project Overview
This project focuses on analyzing Coca-Cola sales data to understand sales performance, product trends, regional performance, and business insights.

## Objectives
- Analyze total sales and revenue.
- Identify top-performing products.
- Analyze sales by region and state.
- Understand monthly and yearly sales trends.
- Create meaningful business insights using data visualization.

## Tools & Technologies
- Microsoft Excel
- Power BI
- Data Cleaning
- Data Visualization

## Key Insights
- Sales performance across different regions.
- Best-performing products.
- Revenue trends and patterns.
- Business performance analysis.

## Project Files
This repository contains the project dataset, analysis files, and dashboard screenshots.
